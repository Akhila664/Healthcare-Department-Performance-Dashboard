# 🏥 Healthcare Department Performance Dashboard

## 📌 Project Overview
This interactive Power BI dashboard provides insights into healthcare department operations, employee distribution, reimbursement trends, and performance metrics to support data-driven decision-making.

---

## 📊 Dashboard Features

- Employee Count by Department
- Annual Reimbursement Analysis
- Actual vs Target Performance Metrics
- Employee Status Distribution
- Policy Exception Distribution
- Reimbursement Distribution by Department (Treemap)
- Interactive Department Filter (Slicer)

---

## 🛠 Tools & Technologies

- Power BI
- SQL
- DAX
- Data Modeling
- Data Visualization
- Healthcare Analytics

---

## 📈 Key Insights

- Total Employees: **381**
- Active Employees: **93.4%**
- Policy Exceptions: **8.8%**
- Department-wise reimbursement analysis
- Actual vs Target performance comparison
